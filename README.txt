DIWALI MAGIC — UPGRADED VERSION
================================

FILES
- index.html   Main website structure
- style.css    Responsive design, animations and themes
- script.js    Personalization, sharing, fireworks, sound and card download

RUN LOCALLY
1. Extract the ZIP file.
2. Open the diwali-magic-upgraded folder.
3. Double-click index.html. It runs in a modern browser.

PUBLISH FREE
1. Open https://app.netlify.com/drop
2. Drag the extracted folder (the folder containing index.html) onto Netlify Drop.
3. Netlify gives you a public website URL. Share that URL.

HOW VISITORS USE IT
1. Open your website link.
2. See the greeting and fireworks. If the URL has ?to=Name, the greeting is personalized automatically.
3. Scroll to "Make it personal", enter a recipient name and choose a message.
4. Preview, share through WhatsApp, copy the link, or save a greeting card PNG.
5. Explore the diya, wish, rangoli/theme and fireworks interactions.

PERSONALIZED LINK EXAMPLE
https://your-site.netlify.app/?to=Rahul&wish=love

SUPPORTED WISH VALUES
blessings, love, success, fun

NO DATABASE
This is a static website. Recipient name and selected wish are encoded in the URL query string.
It does not store visitor names, collect analytics, or save user submissions to a server.
The sound is off by default and only plays after a visitor enables it.

NOTES
- Internet connection is needed for Google Fonts and WhatsApp sharing.
- Download greeting card creates a PNG locally in the visitor's browser.
- Replace the example domain with your actual deployed Netlify URL when sharing.
