DIWALI MAGIC - QUICK START

1. Extract diwali-magic.zip.
2. Open the extracted folder.
3. Double-click index.html to run the website in your browser.
4. Enter a name and click "Open Your Surprise".
5. Use "Share on WhatsApp" to share a personalized link.

CUSTOMIZE:
- Change "Manu" in index.html and script.js to your preferred sender name.
- The optional assets/music.mp3 file is reserved for a future music feature.
- Google Fonts require an internet connection. The website itself runs locally.

DEPLOY:
Upload the project folder to Netlify Drop (https://app.netlify.com/drop)
or publish it using GitHub Pages.

NOTE:
This is a static frontend project. It does not save visitor data or track link opens.
